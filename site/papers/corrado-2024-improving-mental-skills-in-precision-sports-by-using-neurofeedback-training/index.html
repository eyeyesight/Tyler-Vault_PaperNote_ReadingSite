    One-sentence Takeaway

    這篇敘事性回顧整理 1990–2023 年精準運動相關的神經回饋（neurofeedback training, NFT）研究，指出 SMR、theta、alpha 與 Mu 等 EEG 訓練可能改善注意、情緒調節、動作學習與部分射擊／射箭／高爾夫表現，但文中同時保留了無顯著表現提升、特定頻帶訓練造成表現下降與消費級裝置效果不顯著等結果，因此現有證據較適合視為「具潛力但高度依賴 protocol、任務與個體特徵」的研究方向，而非已建立的普遍性績效提升方法。（pp. 5–18；Table 1, pp. 7–9）

    Research Question

    筆記者重建：在射箭、射擊與其他 target-precision sports 中，現有研究如何使用 neurofeedback／neuromodulation 來調節與表現相關的心理、認知與腦波狀態；這些 protocol 對注意、壓力／焦慮調節、動作學習與實際運動表現的證據有多一致；以及未來應如何結合 biofeedback、個人化與新型穿戴技術？（pp. 3–5）

    作者明列四個 review objectives：（1）整合 NFT 改善運動員認知與心理能力的研究，聚焦射箭與射擊；（2）評估 NFT protocol 對精準運動績效的效果；（3）辨識 NFT 可能影響相關認知與心理歷程的理論機制；（4）討論此領域的限制與未來方向。（p. 4）

    Citation

    Corrado, S., Tosti, B., Mancone, S., Di Libero, T., Rodio, A., Andrade, A., & Diotaiuti, P. (2024). Improving Mental Skills in Precision Sports by Using Neurofeedback Training: A Narrative Review. Sports, 12, 70. https://doi.org/10.3390/sports12030070

    Argument Structure

    1. 問題設定：精準運動不只是動作準確度問題。 作者主張射箭與射擊高度依賴專注、情緒控制、壓力管理與認知彈性，因此心理與認知訓練是績效的一部分；這一段主要是 author-cited background，而非本文的新實證結果。（pp. 1–2）
    2. NFT 的基本機制：即時回饋與腦波自我調節。 EEG-based NFT 透過頭皮電極取得神經訊號，再以視覺、聽覺或 audiovisual feedback 讓受試者藉由 operant conditioning 學習調節特定頻帶；作者將此與 neuroplasticity、attentional control、emotional regulation 連結。（pp. 2–4；Figure 1, p. 3）
    3. 一般運動績效證據。 作者先從反應時間、持續注意、壓力與焦慮管理等跨運動研究說明 NFT 的潛力，再轉入 precision sports。（pp. 5–6）
    4. 敘事性文獻彙整。 作者描述 PubMed、Scopus、Web of Science 的搜尋與 1990–2023 年範圍；Table 1 彙整 22 條與 neuromodulation、NFT、precision sports 有關的研究，涵蓋 archery、shooting、golf putting、dart throwing、biathlon，以及少數非典型 precision-sport examples。（pp. 6–9；Table 1）
    5. 核心實證主線：SMR 最接近一致訊號，但其他頻帶結果混合。 射擊／射箭研究反覆出現較高 sensorimotor rhythm（SMR）與較佳表現、以及 SMR NFT 促進表現的結果；相較之下，alpha、frontal theta、Mu 的方向與有效性會依 protocol 與任務改變，且存在 null / negative findings。（pp. 10–14）
    6. 從單一腦波目標轉向整合式 psychophysiological training。 作者在後半部主張將 EEG neurofeedback 與 HRV、EMG、GSR 等 biofeedback 結合，並依個別 athlete profile 客製化，以追求心理與生理狀態的一致性。（pp. 15–17）
    7. 未來技術與研究設計。 結論提出 VR/AR、machine learning personalization、wearable devices、longitudinal studies、interdisciplinary research、ethical/regulatory standards 與跨運動驗證等方向；作者同時承認需要更多嚴謹 controlled trials。（pp. 17–19）

    本文的主要貢獻型態是 narrative synthesis + conceptual/practical agenda，不是新的 experimental test，也沒有進行 meta-analysis 或正式 risk-of-bias synthesis。（§3, p. 6；§6, pp. 17–19）

    Theoretical Background

    • Brain plasticity / neuroplasticity： 作者以神經可塑性作為 NFT 能產生較持久腦波改變的主要理論前提，認為持續回饋可促成對特定 neural activity pattern 的重新調節；這是作者引用既有研究建立的理論背景，不是本回顧直接測得的機制。（pp. 2–4, 9）
    • Psychophysiological model of biofeedback： 藉由即時察覺並調節生理／神經訊號，運動員可能增強自我調節與壓力控制。作者在 §4.1 將此列為 precision sports 中 NFT 的理論基礎。（p. 9）
    • Attentional control theory： 作者以維持 task-relevant focus、排除 distraction 的能力解釋 NFT 為何可能對射擊、射箭等高精度任務有幫助。（p. 9）
    • Psychomotor efficiency / neural efficiency 背景： 熟練與菁英運動員可能呈現更有效率、較少非必要 cortical involvement 的處理模式；作者用 archery / shooting 的 EEG、fMRI 證據支持「技能專精伴隨 neural processing refinement」的敘事。（pp. 10–11）
    • Motor programming： 在 golf putting 等 visuomotor task 中，Mu rhythm 被用來討論 task-relevant 與 task-irrelevant motor programming 的抑制／促進；作者指出目前不同 skill level 與 task complexity 下結果並不完全一致。（pp. 12–13）

    Key Terms and Construct Boundaries

    Neurofeedback training (NFT)以即時神經訊號回饋讓個體學習自我調節 brain function；EEG-based NFT 透過頭皮電極記錄訊號，再以 auditory、visual 或 audiovisual feedback 進行 operant conditioning。本文前段有時把 HRV／呼吸訓練也置於廣義「NFT framework」下，但 §5.3 又明確區分 EEG neurofeedback 與 HRV/EMG/GSR biofeedback；因此「NFT」在本文中的範圍並不完全一致。pp. 2, 15–16
    Sensorimotor rhythm (SMR)文中把 SMR 視為與 sensory-motor regulation、attentional processing 與 precision motor performance 有關的 EEG target；多篇 shooting / archery / golf 研究使用 SMR enhancement。SMR 與較佳表現的關係在本文所列 evidence 中相對一致，但不能由關聯研究單獨推論 SMR 是造成優異表現的機制。pp. 10–14；Table 1
    Frontal midline theta (FMT)與 focused attention / sustained attention 相關的 frontal theta target；NFT 可用來嘗試提高 FMT。Toolis/biathlon 的敘述顯示 FMT 可被短暫提高，但未轉化為顯著 shooting performance improvement；神經 target 可訓練不等於行為績效有效。pp. 11–12
    Alpha rhythm8–12 Hz；作者將其與 relaxed wakefulness、relaxation、stress/anxiety regulation 連結。Figure 1 的 cognitive-state mapping 是概念性對照，不是本文直接驗證的一對一 mapping；此外 Gong et al. 2020 的 alpha NFT group 出現 shooting performance 下降，顯示「提高／調節 alpha 必然有益」不成立。Figure 1, p. 3；Table 1, p. 8
    Theta rhythm約 4–8 Hz；文中在不同脈絡下連結 sustained attention、meditation、mental imagery，也有 protocol 以抑制 theta 或增強 FMT theta。「theta」不是單一方向的 performance target：不同位置、功能與 protocol 可能要求 enhancement 或 suppression，不能只用頻帶名稱推斷訓練方向。pp. 2–3, 5, 11–12
    Mu rhythm文中以 8–13 Hz 的 sensorimotor Mu rhythm 討論 motor programming；增加或降低 Mu power 被假設可能分別抑制或促進不同 motor programming processes。Mu 與 SMR 在頻率範圍上可能重疊，但本文將其置於不同理論脈絡；golf studies 對 Mu NFT 的長期 retention 效果並不一致。pp. 12–14
    Biofeedback§5.3 將 HRV、EMG、GSR 分別對應 autonomic regulation、muscle tension control、emotional arousal / stress response management。這些是 physiological biofeedback，不等同 EEG neurofeedback；作者主張未來整合兩者，而非用其中一者取代另一者。pp. 15–16
    Precision sports / target-precision sports以射箭、射擊、golf putting 等高度依賴準確度、細微動作控制、專注與情緒穩定的運動作為核心。本文實際納入的例子比此範圍更寬，包含 ice hockey shooting、biathlon、dart throwing 與「various sports」；review scope 與實際 evidence corpus 有一定鬆動。pp. 1, 4, 6–9

    Methods

    Method

    Design or Approach

    本文是 narrative review。作者表示因領域仍具 exploratory nature、研究方法與結果高度多樣，因此認為目前不適合系統性回顧；同時承認 narrative review inherent selection bias，並表示有意納入正向與負向結果以降低偏差。（§3, p. 6）

    作者沒有進行新的 participant-level data collection；Institutional Review Board 與 informed consent 均標示 not applicable，也未產生或分析新資料。（p. 19）

    Participants, Data, or Source Corpus

    • 資料來源為既有文獻；作者列出的核心資料庫為 PubMed、Scopus、Web of Science。（p. 6）
    • 搜尋時間涵蓋 1990–2023 發表的研究。（p. 6）
    • Table 1 逐列可辨識 22 條相關研究，跨 archery、shooting、golf putting、dart throwing、biathlon、ice hockey，以及一般／多項運動研究。（Table 1, pp. 7–9；筆記者依表格逐列計數）
    • 研究樣本從 novice、students、pre-elite、experienced 到 elite athletes 皆有，也包含極小型 case study（例如兩名 archers）。（pp. 7–9, 12）

    Task, Procedure, or Search Strategy

    作者報告使用的關鍵詞包括 “neurofeedback”, “precision sports”, “target shooting”, “archery”。（p. 6）

    納入標準概括為「與 neurofeedback 在 sport performance 的應用有關」；排除標準為「不直接涉及 neurofeedback 或 precision sports」的研究。作者另外將搜尋主題分為六類：（1）NFT 與 cognitive performance；（2）sports performance 的 physiological aspects；（3）mental skills / psychological aspects；（4）NFT technological advancements；（5）ethical and methodological considerations；（6）specific sports 中的 NFT。（p. 6）

    文中未提供完整 Boolean search strings、各資料庫的搜尋日期、去重方式、title/abstract/full-text screening 流程、reviewer 數量、衝突解決方式或 PRISMA-style flow。（p. 6；全文未報告）

    Measures, Labels, or Constructs

    由於是 narrative review，本文未使用單一 outcome measure；被整合的主要 constructs / outcomes 包括：

    • sport performance：shooting score / accuracy、archery performance、golf putting、dart throwing、ice-hockey shooting；
    • attentional constructs：concentration、sustained attention、executive control network、attentional focus；
    • affective / psychophysiological outcomes：anxiety、stress、arousal、mental resilience、heart rate / HRV；
    • neural outcomes：SMR、alpha、theta / FMT、Mu、QEEG markers、EEG network coupling / coherence；
    • learning outcomes：motor learning、retention、novice-to-skilled acquisition。（pp. 5–16；Table 1）

    Analysis, Evaluation, or Synthesis

    作者表示會依研究的 design、participant demographics、NFT protocols 與 performance outcomes 進行整理，並以 narrative synthesis 系統性摘要各研究的 key outcomes。（p. 6）

    沒有報告：formal effect-size aggregation、heterogeneity statistics、risk-of-bias / quality assessment、certainty grading、publication bias assessment、sensitivity analysis、protocol registration 或 preregistration。（§3；全文未報告）

    Detailed Results

    Result Area 1 — SMR as the most consistent precision-performance target

    • Evidence or statistics: Chang & Hung 的回顧被作者用來指出，在所比較的 cortical components 中，只有 sensorimotor rhythm (SMR) 對 higher-order precision motor performance 呈現較一致、較接近 causal 的 evidence；left temporal alpha、frontal theta 與 alpha 則不一致。（p. 10）
    • Cheng et al. 的 experienced air-pistol study 被描述為：24 名 shooters 中，較佳 shooting performance 與較高 SMR power、較低 Fz–T3 alpha power 相關。（pp. 10–11）
    • Paul et al. 2012 的 28 名 university archers 經 4 週、12 次 NFT，protocol 以增強 SMR、抑制 theta 為主；作者報告其 psychophysiological state、EEG components、score regularity 與 accuracy 改善。（p. 11）
    • Table 1 亦列出 Cheng et al. 2015 golf putting、Cheng et al. 2017 shooting、Gong et al. 2020 shooting 等 SMR-oriented studies 的正向結果。（pp. 7–8）
    • Interpretation boundary: 這些結果跨不同 skill level、運動、電極位置與訓練方式，且回顧沒有統一 effect size 或 bias assessment；因此最多支持「SMR 是值得優先驗證的 target」，不能由本文確立單一 SMR protocol 對所有 precision tasks 有效。
    • Source locator: pp. 10–14；Table 1, pp. 7–9。

    Result Area 2 — Negative, null, and mixed findings matter

    • Evidence or statistics: Gong et al. 2020 的 shooting NFT comparison 在 Table 1 中被概括為：SMR group shooting performance 改善，但 alpha group performance 下降。（Table 1, p. 8）
    • Experienced biathletes 的 FMT study 中，NFT 可暫時提高 frontal midline theta power，但 control 與 experimental groups 在 post-training shooting performance 沒有顯著 interaction；只有 attentional focus 呈 small positive effect，且較有經驗者較能提高 FMT，仍未轉化成 shooting performance。（pp. 11–12）
    • Novice golfers 的 frontal alpha suppression NFT 在 Ring et al. 的研究中未顯示相較 control 的顯著 performance improvement。（p. 13）
    • MUSE ten-pin bowling study以單次 15 分鐘 auditory NFT 進行介入；NFT 組 score 略高、anxiety score 亦不同，但兩者皆 未達統計顯著。（p. 14）
    • 作者也引用既有 meta-analysis，明確寫到 NFT 對 sports performance 的 effect 仍弱，並因此主張需要標準化 protocol 與新技術。（p. 14）
    • Interpretation boundary: 「能改變 target EEG power」與「能改善 task performance」是兩層不同 outcome；本文內部的 null / negative findings 顯示不可用 neurophysiological trainability 代替 behavioral efficacy。
    • Source locator: pp. 11–14；Table 1, p. 8。

    Result Area 3 — Attention, anxiety, and self-regulation outcomes

    • Evidence or statistics: 一般運動研究部分將 NFT 與反應時間、sustained attention、stress / anxiety management 聯結；例如 judo 與 skating studies 被作者描述為 reaction time improvement，alpha training 被用來討論 relaxation 與 HRV。（p. 5）
    • Kavianipoor et al. 2023：20 名具有 trait anxiety 的女性參與者分為 NFT 與 control，均做 dart practice，NFT 組另接受 SMR enhancement、theta presentation、alpha enhancement，共 14 sessions；最後在 executive control network 與 dart-throwing ability 上出現組間顯著差異。（p. 11）
    • Mutang et al. 2023：兩名 archers 接受 8 次 NFT，以提高 SMR 並抑制 high-frequency theta 與 beta；作者報告 STAI、Sport Anxiety Scale-2、GAD-7 相關 anxiety symptoms 下降，mental resilience（confidence、perseverance、control）改善。（p. 12）
    • Interpretation boundary: dart study 樣本小，archery anxiety study只有兩個 cases；這些結果支持 feasibility / hypothesis generation，不能據此估計一般 athletes 的平均效果或長期穩定性。
    • Source locator: pp. 5, 11–12；Table 1, pp. 8–9。

    Result Area 4 — Motor learning and retention in golf

    • Evidence or statistics: Wang 的 novice-golfer study 比較 decreased Mu、increased Mu 與 dummy groups；作者報告 decreased-Mu group 在 EEG-NFT 後 Mu power 顯著降低，伴隨較佳 perceived action control 與 golf performance，並據此提出 Mu power 與 putting performance 的 potential causal connection。（p. 12）
    • Afrash et al. 2023 以 64 名成人 novice golfers 比較 three protocols：Cz SMR enhancement、Fz alpha suppression、Cz Mu suppression。acquisition phase control 與 experimental groups 沒有顯著差異；short-term retention 三個 NFT groups 均優於 control；long-term retention 則只有 SMR 與 alpha groups 優於 sham，Mu group 不再顯著較佳。（p. 13）
    • Pourbehbahani et al. 2023 以 40 名 novice golfers 比較 SMR NFT × self-controlled practice；兩種 intervention 各自改善 acquisition / post-test，但未觀察到兩者的正向交互作用；只有 NFT 在 follow-up 維持正向效果。（pp. 13–14）
    • Interpretation boundary: acquisition、retention 與 follow-up 是不同 learning claims；即時 performance gain 不應自動等同 motor learning。本文所列研究反而顯示 retention phase 可能比 acquisition 更能區分 intervention effect。
    • Source locator: pp. 12–14。

    Result Area 5 — Integrated neurofeedback and physiological biofeedback

    • Evidence or statistics: §5.3 將 EEG neurofeedback 與 HRV、EMG、GSR biofeedback 分開描述，分別針對 cognitive control、autonomic regulation、muscle tension、emotional arousal；作者主張在 precision sports 中整合這些 modalities 可能更貼近「同時需要 cognitive focus 與 physiological calmness」的任務需求。（pp. 15–16）
    • Table 1 亦包含 Christie et al. 2020 的 integrated neurofeedback + biofeedback ice-hockey shooting intervention，作者將結果概括為 improved shooting performance。（p. 8）
    • Interpretation boundary: 本文沒有建立一個標準化 multimodal protocol，也沒有跨研究量化「整合式」相較「單一 NFT」的增益；因此「synergy」主要仍是作者的整合性主張與 future direction。
    • Source locator: Table 1, p. 8；§5.2–5.4, pp. 15–17。

    Result Area 6 — Mobile and consumer-grade EEG

    • Evidence or statistics: Raza et al. 的 11 名 ten-pin bowlers study 使用 MUSE headset，在安靜房間進行單次 15 分鐘 NFT；feedback 為可隨 distraction / attention stability 改變的環境聲音，participants 被要求保持平靜、專注呼吸。（p. 14）
    • NFT 組平均 performance 趨勢較高，但差異不顯著；anxiety measures 亦有組間差異趨勢但不顯著。（p. 14）
    • 作者引用 consumer-grade EEG / fNIRS literature 指出低成本設備的 neuroscience utility 與 accessibility 潛力，但也強調 consumer devices 並非為臨床或研究用途設計，訓練 protocol、expertise 與 customization 仍需要專業監督。（pp. 14–15）
    • Interpretation boundary: accessibility ≠ validity；wearability 與成本降低並不能直接保證 signal quality、protocol fidelity 或 performance efficacy。
    • Source locator: pp. 14–15。

    Discussion

    Authors’ Discussion

    Conclusions

    作者總結 NFT 有潛力改善精準運動員的 concentration、stress / anxiety management、reaction time、sustained attention、emotion management 與部分 performance outcomes，並視 neuromodulation 為射擊與射箭 mental / cognitive skills training 的 promising strategy。（pp. 17–19）

    不過作者同時承認此領域需要更多 rigorous, controlled research，特別是 randomised controlled trials，才能對「NFT 是否能穩定提升 precision-sport mental skills 與 performance」做更確定的結論。（p. 18）

    Explanations

    作者主要以三條機制敘事解釋可能效果：

    1. 透過 operant conditioning 學習調節 brain-wave patterns；
    2. neuroplasticity 使反覆訓練產生較長期的神經適應；
    3. 調節與 attention、emotional regulation、motor programming 有關的 neural activity，使 athlete 更能維持 task-relevant focus、降低 non-essential interference。（pp. 2–4, 9–14）

    後半部則再加入 psychophysiological coherence 的觀點：precision performance 同時受 neural、autonomic、muscular 與 emotional processes 影響，因此 EEG-NFT 搭配 HRV／EMG／GSR biofeedback 可能比只調一個 EEG target 更完整。（pp. 15–17）

    Applications

    作者提出的實務方向包括：

    • 將 NFT 作為傳統 precision-sport training 的補充，而非替代 physical practice；（pp. 17–19）
    • 將 motor imagery 與 neurofeedback 結合，利用 mental rehearsal 支援精細動作學習；（pp. 11, 17）
    • 依 athlete baseline EEG、HRV、behavioral / psychophysiological profile 個人化 protocol；（pp. 16–18）
    • 將 VR/AR、machine learning 與 wearable NFT 納入高壓情境模擬、personalization 與 remote / routine training；（p. 18）
    • 建立兼顧 privacy、fairness、misuse 的 ethical / regulatory guidelines。（p. 18）

    Limitations

    作者明確承認：

    • narrative review 天生具有 selection bias；作者表示已嘗試平衡正負結果，但沒有 formal bias assessment。（p. 6）
    • precision-sport NFT studies 仍少，且在 sample、intervention methodology 與 sport discipline 上不一致，導致 neuromodulation findings 有顯著 inconsistency。（p. 15）
    • sports-performance effect 在既有 meta-analysis 中仍弱，因而需要標準化 protocol 與更準確的效果評估。（p. 14）
    • consumer-grade EEG devices 的 scientific evidence 仍有限，硬體低成本不代表訓練本身不需要專業 protocol 與 supervision。（pp. 14–15）
    • 結論中明確要求更多 randomized controlled trials 才能建立較確定的 efficacy conclusion。（p. 18）

    Future Research

    作者提出七個主要方向：（pp. 18–19）

    1. NFT × VR/AR，模擬競賽壓力；
    2. machine-learning-based personalized NFT；
    3. wearable / user-friendly neurofeedback devices；
    4. longitudinal studies + big data；
    5. neuroscience、sport psychology、cognitive science、sports medicine 的 interdisciplinary collaboration；
    6. ethical / regulatory standards；
    7. 將 NFT 驗證範圍擴展到更多 team / endurance sports。

    另在 §5 中特別主張更深入測試 EEG neurofeedback 與 HRV、EMG、GSR biofeedback 的 integrated protocols，以及針對 athlete psychophysiological profile 的個人化訓練。（pp. 15–17）

    Missing or Unclear Information

    • 文中未報告各資料庫的完整搜尋字串、搜尋執行日期、去重規則、初始命中篇數、篩選排除篇數與 full-text exclusion reasons，因此無法重現 review corpus 的形成過程。（§3, p. 6）
    • 文中未報告是否由多位 reviewers 獨立 screening / extraction，以及 disagreement resolution procedure。（§3, p. 6）
    • 文中未提供 included studies 的 formal risk-of-bias / quality assessment，也沒有 certainty-of-evidence grading。（全文未報告）
    • 作者稱 review 聚焦 precision sports，且方法段說明已「delimiting the study to precision shooting disciplines」，但 Table 1 仍包含 ice hockey、various sports、golf、darts、biathlon；scope boundary 沒有完全明確化。（p. 6；Table 1, pp. 7–9）
    • 引用編號疑似不一致： Table 1 將 experienced biathletes 的 FMT neurofeedback study 列為 Toolis et al. [55]，但 §4.4 詳述相同研究時引用 [64]；reference [64] 實際列為 Li et al. 2021 的 interoceptive attention paper。這使 detailed narrative 的 source attribution 需要回查原始 Toolis paper。（pp. 9, 11–12, 21）
    • Figure 1 對頻帶範圍的標示與正文略有差異：正文將 delta 寫為 1–4 Hz、gamma 為 30 Hz 以上；Figure 1 則標 delta 0.5–4 Hz、gamma 30–100 Hz。對本回顧結論影響不大，但顯示頻帶定義未完全統一。（pp. 2–3；Figure 1）
    • 目前提供的主文包含完整 references 與 Table 1，但未看到 supplementary material；作者也未在 Data Availability 中指出有新資料或 supplement 可供重現。（p. 19）

    Critical Appraisal

    Strengths

    • 保留異質與反例。 雖然整體敘事偏向 NFT 的潛力，作者仍呈現 alpha group performance decline、FMT 被成功調節但 shooting performance 未改善、MUSE intervention 不顯著、golf alpha suppression null result 等 evidence，避免完全 promotional 的結論。（pp. 11–14；Table 1）
    • 把 neurophysiological target 與 behavioral outcome 放在同一脈絡。 特別是 FMT、SMR、Mu examples，有助於區分「腦波是否可訓練」與「運動表現是否因此改善」兩個層次。（pp. 10–14）
    • 跨層次整合。 從 EEG bands、attention / anxiety、motor programming，到 HRV / EMG / GSR 與 consumer devices，為 precision-sport neuromodulation 提供較寬的 landscape。（pp. 2–18）
    • Table 1 提供可作為後續 literature mapping 的入口。 22 條研究以 sport、sample、protocol 與 results 方式整理，雖然摘要粒度粗，但適合做後續 source chasing。（pp. 7–9）

    Methodological Concerns

    • Narrative-review selection process 不可重現。 沒有完整 search strings、screening flow、double screening、quality appraisal 或 protocol registration，因此作者即使主張納入正反證據，仍無法排除 selection bias、citation bias 與 selective emphasis。（p. 6）
    • Evidence hierarchy 混合。 Table 1 把 observational EEG correlates、experimental NFT、case study、review、fMRI study 等並列在同一「Results Obtained」欄，容易讓讀者把 neural correlates 與 intervention efficacy 當成同等程度證據。（pp. 7–9）
    • Construct boundary 不穩定。 前文把 HRV / respiratory training 納入 NFT 的 broader framework，後文才把 EEG neurofeedback 與 physiological biofeedback 分開，可能混淆「neurofeedback」與「biofeedback」的 intervention class。（pp. 2, 15–16）
    • Protocol heterogeneity 很大。 enhancement / suppression 的頻帶、electrode site、training dose、feedback modality、participant expertise 與 task 都不同；用「NFT」作為單一 intervention category 會掩蓋實際上可能是多種不同 treatment。（pp. 7–14）
    • Outcome heterogeneity 與效力不明。 performance score、attention、anxiety、HRV、EEG power、motor learning retention 被同時視為「benefit」，但不同 outcome 的實務意義、measurement reliability 與 transfer 距離不同。（pp. 5–16）
    • 引用錯置風險。 biathlon FMT study 的 [55]/[64] mismatch 表示至少有一處 reference attribution 需要人工核對，降低 review 作為 secondary source 時的可追溯性。（pp. 9, 11–12, 21）

    Alternative Interpretations

    • 非特異性訓練效應： performance improvement 可能部分來自額外練習時間、expectancy、attention to task、motivation、coach interaction 或 self-monitoring，而不完全來自成功調節特定 EEG band。若 sham / active control 不充分，這些因素無法排除。
    • state marker 而非 causal control variable： 熟練者在成功 shot 前具有較高 SMR、特定 coherence 或 hemispheric asymmetry，可能是 expertise / preparation state 的結果，而不是只要人工把該頻帶提高就能複製 superior performance。
    • skill-level moderation： biathlon study 顯示較有經驗者更能調高 FMT，但 performance 仍未改善；這可能代表 NFT trainability 與 behavioral transfer 受既有 expertise、ceiling effect 或 task automaticity 調節。
    • task-specificity： golf putting、archery release、pistol shooting 與 dart throwing 雖都具有 precision component，但感知需求、動作時間尺度、姿勢控制、decision load 與 feedback cycle 不同；跨 task 重複看到同一 band 不代表相同功能機制。
    • publication / reporting bias： 在沒有 formal bias assessment 的 narrative corpus 中，正向 NFT studies 可能較容易被發表或被回顧選入，使整體敘事高估效果一致性。

    Evidence Needed to Resolve Uncertainty

    • 以 preregistered randomized, double-blind / assessor-blind, active-sham controlled trials 分離特定 EEG modulation 與 expectancy / additional-practice effects；同時報告 EEG trainability 與 sport-performance transfer，而不是只報其一。
    • 在同一 sport task 中直接比較 SMR enhancement、alternative-frequency training、sham，並預先指定 electrode site、dose、primary behavioral outcome 與 retention test，以判斷頻帶特異性。
    • 對成功與失敗 learner 進行 baseline EEG / HRV / expertise stratification，測試「誰能學會調節」與「誰會有 behavioral transfer」是否是兩個不同 predictor problem。
    • 加入 retention 與 transfer tests：至少比較 immediate post-test、短期 retention、長期 retention，以及未訓練但結構相近的 precision task，區分短暫 state change 與 motor learning。
    • 對 multimodal protocol 採用 factorial design（例如 EEG-NFT × HRV biofeedback），才能判斷 integrated training 是否真有 additive / synergistic effect，而非只是增加 training dose。
    • 對 mobile / consumer EEG 應同時驗證 signal quality、artifact robustness、target-frequency estimation 與 laboratory-grade system agreement，再談 field deployment efficacy。

    Relevance to My Research

    Claims Supported

    • 對 Racing Simulator EEG 的 bounded support： 本文支持把「神經訊號是否可被調節」與「任務績效是否因此提升」拆成兩個 primary evidence questions。precision-sport literature 中 FMT 可上升但 shooting performance 無顯著改善，是這個區分最直接的例子。（pp. 11–12）
    • 本文也支持將 behavioral performance + EEG + autonomic / physiological measures 視為互補層次，而非只靠單一 EEG marker 推論 mental state；§5.3 對 HRV、EMG、GSR 的區分可作為 multimodal analysis 的設計參考。（pp. 15–16）
    • 對 skill acquisition / expertise comparison，本文提供一個可借鏡的分析框架：比較 novice / experienced / elite 的 neural pattern，再另外檢驗該 pattern 是否能被 intervention 操作並轉化為 performance change。（pp. 10–14）

    Claims Challenged

    • 本文挑戰「只要找到 expert EEG signature，就能直接拿來做 neurofeedback target」的簡化假設。observational correlate、trainability 與 performance efficacy 在多個研究中並未完全對齊。（pp. 10–14）
    • 本文也挑戰「提高 relaxation-associated alpha 一定有助於表現」的直覺：Gong et al. 2020 的 alpha group 反而出現 shooting performance decrease。（Table 1, p. 8）

    Design Implications

    • 筆記者推論 — 必須重新驗證於賽車任務： 若在 Racing Simulator EEG 中考慮 neurofeedback，應先用現有 simulator performance data 建立 task-specific neural / physiological correlates，而不是直接移植 shooting / archery 的 SMR、alpha 或 FMT target。賽車是連續、動態、含高頻 decision-making 的任務，與 pre-shot discrete precision task 的 temporal structure 不同。
    • 筆記者推論： 可把 neurofeedback research 分成三階段：① baseline marker discovery；② neurofeedback trainability；③ behavioral transfer / retention。只有三者串起來，才能宣稱某 neural target 對 simulator performance 具有介入價值。
    • 筆記者推論： 若未來加入 biofeedback，HRV 可對應 autonomic regulation、EMG 可對應 unnecessary muscle tension、GSR 可對應 arousal；但這些指標與 lap time、line consistency、brake/throttle control 的關係都必須在 racing context 重新驗證，不能由 precision-sport review 直接外推。
    • 筆記者推論： 實驗應優先保留 sham / active-control 與 retention test，以避免把 extra practice、feedback expectancy 或短期 arousal change 誤認為 neurofeedback-specific learning。

    Use in Current Projects

    • Racing Simulator EEG： 可作為 neurofeedback / biofeedback 實驗延伸的上游 review source，特別適合用於決定「哪些 EEG target 值得先做 baseline validation」、「intervention outcome 必須同時包含哪些 behavioral / psychophysiological layers」，以及「為什麼需要 control + retention」。
    • 本文不直接驗證 racing、motorsport 或 continuous driving task；因此它對 Racing Simulator EEG 的角色是 design lens / hypothesis source，不是 evidence of efficacy in racing。

    Open Questions

    • Table 1 的 22 條研究是否能重建成一個完整、可重現的 search corpus？需要取得各資料庫完整 search strategy 與 screening record 才能判斷。
    • experienced biathletes 的 FMT study 在正文 [64] 與 Table 1 [55] 的 reference mismatch，應以 Toolis et al. 原文核對實際 sample、training dose、statistical model 與 effect magnitude。
    • SMR 在 shooting / archery / golf 中相對一致的結果，究竟是共同的 precision-motor mechanism，還是不同 task 下多個機制碰巧投射到相似頻帶？需要 task-matched experiments 才能區分。
    • 對 Racing Simulator EEG 而言，哪些 neural marker 是 discrete precision-sport evidence 可合理轉化的「hypothesis」，哪些則因 continuous control、visual flow、decision load 與動作頻率不同而應完全重新探索？
    • 若建立 multimodal neurofeedback + biofeedback protocol，應優先測試 additive effect、synergistic effect，還是先證明每一 modality 各自能在 simulator context 中產生 behavioral transfer？
