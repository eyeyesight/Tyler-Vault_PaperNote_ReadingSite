    One-sentence Takeaway

    本系統性回顧與統合分析彙整健康成人的受控 EEG neurofeedback training（EEG NFT）研究，報告其對 sport motor performance 具有中度正向整體效果（Hedges’s g = 0.78, 95% CI [0.49, 1.07]），且 CRED-nf 方法學評分較高的研究呈現較大效果，但研究間仍有中度異質性、盲法與配置隱蔽普遍不足，且多數證據集中於精準型運動，因此不能由此直接推論特定 NFT protocol、訓練劑量或跨運動情境都具有同等效果。（p. 1, 6–12；Figure 2；Figure 3）

    Research Question

    • 筆記者重建：在健康成人的受控研究中，EEG neurofeedback training 是否能改善運動相關的 motor performance，其整體效果量與研究間異質性為何？（p. 2–4）
    • 筆記者重建：以 CRED-nf checklist 評估的 neurofeedback 方法學品質，是否與 NFT 對 sport performance 的效果大小有關？作者明確提出主要假設：CRED-nf 得分較高的研究應呈現較強的 neurofeedback 效果。（p. 2）
    • 筆記者重建：participant expertise、是否將 NFT 整合進運動動作、訓練 session 數、performance type、training target 數量與 personalized feedback，是否可解釋不同研究效果的差異？這些項目被列為 moderator analyses，而非全部被作者表述為事前確認性假設。（p. 2, 4）

    Citation

    Yu, C.-L., Cheng, M.-Y., An, X., Chueh, T.-Y., Wu, J.-H., Wang, K.-P., & Hung, T.-M. (2025). The Effect of EEG Neurofeedback Training on Sport Performance: A Systematic Review and Meta-Analysis. Scandinavian Journal of Medicine & Science in Sports, 35, e70055. https://doi.org/10.1111/sms.70055

    Argument Structure

    1. 作者先指出 EEG NFT 因時間解析度、可攜性與運動場景適應性而適合 sport performance，但既有研究在實驗設計、參數與結果上高度不一致，先前 meta-analysis 對 motor performance 的涵蓋也不完整。（p. 2）
    2. 作者主張近年新研究快速增加，因此有必要更新 evidence base，並將範圍限制在 sport motor performance，而不是混合 cognitive tests、questionnaires 或未受控研究。（p. 1–3）
    3. 本研究預先註冊 protocol，依 PRISMA 執行系統搜尋，納入 RCT 與 non-randomized controlled study，並以 PEDro 評估一般 trial quality、以 CRED-nf 的 essential items 評估 neurofeedback-specific reporting/design quality。（p. 2–4）
    4. Meta-analysis 以 Hedges’s g 彙整 NFT 相對控制條件的 motor-performance change，採 random-effects model，並檢驗 heterogeneity、publication bias 與多個 moderator。（p. 3–4, 6）
    5. 結果顯示整體效果為中度正向；CRED-nf 高於中位數的研究效果顯著大於低於中位數者；expertise 僅接近顯著，其餘 moderator 的 subgroup differences 均不顯著。（p. 6–10；Figure 3）
    6. 作者因此將主要實務結論放在「提高 neurofeedback 研究方法與報告品質」而非指定某一 protocol 必然最有效，並要求未來研究強化 sham control、regulation-success manipulation check、長期 retention 與對運動需求的個別化設計。（p. 9–12）

    Theoretical Background

    • **EEG NFT 作為 performance enhancement 工具：**作者援引既有文獻，將 neurofeedback 定義為個體感知並學習調節自身腦訊號的閉迴路訓練；相較 fMRI/NIRS，EEG 因高時間解析度、可攜性與運動場景適用性而被廣泛使用。這是作者引用的背景，不是本研究直接測得的結果。（p. 2）
    • **運動表現與神經調節：**作者引用既有研究指出 EEG NFT 曾被用於 focus、memory、motor skills 與精準運動表現，如 golf putting、archery 與 shooting；但先前 meta-analysis 對 EEG change 與 performance improvement 的證據並不一致。（p. 2）
    • **Psychomotor efficiency hypothesis：**在 discussion 中，作者以此框架解釋高水準表現可能涉及更選擇性、較有效率且較自動化的 neural processing；並以單次 SMR NFT 研究中較低 attentional engagement、較低 conscious motor control 與較高 relaxation 作為與此框架相容的例子。這屬作者對既有與納入研究的理論解釋，並非本 meta-analysis 直接檢驗其機制。（p. 12）
    • **Motor learning / expertise：**作者認為 novice 與 expert 可能位於不同學習階段，因此可影響可改善空間與 NFT 的效果；但跨運動的 expertise 分類缺乏統一量尺。（p. 2, 11）
    • **Integrated NFT：**作者援引先前文獻主張若 NFT 與目標 sport motor task 同時進行，可能促進 neuroregulation 與 motor execution 的連結與 transfer；本研究則直接檢驗此 moderator，但沒有發現顯著 subgroup difference。（p. 2, 4, 11）

    Key Terms and Construct Boundaries

    TermSource DefinitionBoundary or DistinctionSource Locator
    Neurofeedback training (NFT)個體感知並從自身 brain signals 學習，以調節 neural activity 的訓練方法。本文只統整使用非侵入式 EEG-NFT 的研究；不能把 fMRI/NIRS neurofeedback 的效果併入本研究結論。p. 2, Section 1；p. 3, Section 2.1
    Sport motor performance納入標準將 motor performance 界定為可觀察的 muscular outputs，包括 reaction time、movement precision / dexterity 與 overall body balance。本文刻意排除只測 cognitive test 或 questionnaire 的研究；「sport performance」在本 meta-analysis 實際上主要指 motor-performance outcomes。p. 3, Section 2.4
    CRED-nf checklist用於 clinical 與 cognitive-behavioral neurofeedback study reporting / experimental design 的 consensus-based checklist。本研究使用其中的 essential items 做方法學評估；其得分是 reporting/design quality 指標，不等同直接測量 intervention efficacy。p. 2–4, Sections 1, 2.6, 2.8；p. 8, Table 2
    Integrated NFTNFT 與 sport motor task 同時進行，例如一邊接受 neurofeedback、一邊投籃或 putting。若只進行 neurofeedback、沒有同步 motor task，歸為 unintegrated；這是 intervention format 分類，不代表較高 ecological validity 已被證實。p. 4, Section 2.8
    Personalized feedback依個體表現提供特定調節指引，例如針對個人 mental state 給予具體建議。所有人接受相同 standardized feedback 則被歸為 general instruction；本研究沒有發現 personalized feedback 的顯著 moderator effect。p. 4–5, Section 2.8；p. 10, Figure 3D
    Participant level研究依 expert 或 novice 分組。作者指出跨不同運動的 expert/novice 判定不一致，建議使用更量化、sport-specific 的表現指標；因此此分類不應視為完全可比的 expertise construct。p. 4, Section 2.8；p. 11, Section 4.2
    Hedges’s g本研究以 standardized effect size 表示 NFT 相對 control 的差異，並引用 Cohen 的 0.2 / 0.5 / 0.8 作為 small / moderate / large 參考。effect size 是不同 outcome 的標準化差異，不代表所有 sport tasks 使用相同單位，也不直接指出臨床或競賽上的實質重要性。p. 3, Section 2.7
    Regulation successCRED-nf 要求根據 feedback signal 報告 participant 是否成功調節目標 neurofeedback variable。regulation success 與 behavioral improvement 是不同 evidence layer；兩者是否相關應另外以 correlation / association 分析檢驗。p. 6, Section 3.4；p. 8, Table 2

    Methods

    Method

    Design or Approach

    • 系統性回顧與統合分析；protocol 註冊於 PROSPERO，registration number CRD42021238399，並宣稱遵循 PRISMA guidelines。（p. 2, Section 2）
    • Eligibility 依 PICOS：healthy human adults 18–64 years；intervention 為非侵入式 EEG-NFT；comparator 可為 sham neurofeedback、conventional training 或 no intervention；outcome 為 NFT 前後的 sport motor performance；study design 可為 RCT 或 non-randomized controlled study（NRS）。（p. 3, Section 2.1）
    • Qualitative synthesis 另要求 NFT、motor-performance outcome、control group/condition、English peer-reviewed original article，以及 RCT/NRS；meta-analysis 再要求足夠 effect-size data 且被評估為 low 或 moderate risk of bias。（p. 3, Section 2.4）
    • 本文主文報告 qualitative synthesis 納入 25 studies、meta-analysis 納入 21 studies；study-count 與 flow diagram / Table 1 的呈現存在若干不一致，詳見 Missing or Unclear Information。（p. 4–6；Figure 1；Table 1）

    Participants, Data, or Source Corpus

    • 搜尋範圍限 healthy adults 18–64 years。（p. 3, Section 2.1）
    • 納入研究發表年份橫跨 1991–2025，作者稱超過一半在 2017 年後發表。（p. 6, Section 3.2）
    • Qualitative corpus 涵蓋 archery、rifle / pistol / air-pistol shooting、golf putting / golf long game、dance、dynamic balance、cycling time-to-exhaustion、soccer / sprint hurdle 等任務；作者指出多數研究集中於 precision movements。（p. 5–6, Table 1 and Section 3.2）
    • Meta-analysis 的 Results 文字報告「21 studies, involving a total of 271 participants」；但 Figure 3A 的 arm-level N 呈現方式未在主文中與此 unique-participant count 明確對帳，尤其部分研究可能涉及 crossover / repeated-condition 設計。（p. 6, Section 3.5；p. 9, Figure 3A）

    Task, Procedure, or Search Strategy

    • Databases：PubMed、Scopus、Web of Science。（p. 3, Section 2.2）
    • 納入「published prior to January 2025」的研究；限 English、peer-reviewed journal original research。PubMed 搜尋使用 MeSH；完整 search terms 位於 Appendix S1，但本次提供的主文 PDF 未包含該 supporting file。（p. 3, Section 2.2）
    • Title/abstract screening 由兩位作者獨立執行；full-text review 由三位作者執行；以 Microsoft Excel 記錄 eligibility，爭議經共識與領域專家討論解決；另檢查納入研究的 reference lists。（p. 3, Sections 2.3–2.4）
    • Data extraction 由三位作者獨立進行，有歧異則討論至共識。（p. 3, Section 2.4）
    • 作者沒有聯絡原研究作者補取 missing data 或細節。（p. 3–4, Section 2.7）

    Measures, Labels, or Constructs

    • **Motor-performance outcomes：**reaction time、movement precision、dexterity、overall body balance 等可觀察 motor outputs。（p. 3, Section 2.4）
    • **EEG targets：**納入研究常見 theta（4–7.5 Hz）、alpha（8–13 Hz）、SMR（12–15 Hz）、beta（15–30 Hz）；常用 electrode locations 包括 C3、Cz、C4、Pz。（p. 6, Section 3.2）
    • **Intervention duration：**由單次約 30 min 到 15 sessions、累積 900 min、跨 4.5 months。（p. 6, Section 3.2）
    • **Control conditions：**作者描述包括 sham feedback、alternate EEG-frequency protocols、一般 training without neurofeedback、rest/no intervention 等；不同研究控制條件並不一致。（p. 5–6, Table 1 and Section 3.2）
    • **Study quality：**以 PEDro scale 評估；若 PEDro database 無分數，由受過 PEDro training 的三位作者獨立評分並經討論裁決。（p. 3, Section 2.5）
    • **Neurofeedback-specific quality：**以 CRED-nf essential items 評估，並依 median 將研究分為 higher-than-median 與 lower-than-median。（p. 3–4, Sections 2.6, 2.8）
    • **Moderators：**expert vs novice、integrated vs unintegrated、sessions（1–3 / 4–8 / 9+）、precision vs other、single vs multiple training targets、specific/personalized vs general instruction。（p. 4–5, Section 2.8；p. 10, Figure 3D）

    Analysis, Evaluation, or Synthesis

    • Effect size 有兩種計算路徑：crossover post-test trial 以 NFT 與 control outcome 差異除以 combined SD；pre-post control design 則比較 NFT 與 control 的 change scores，再以估計的 pooled change SD 標準化；最終以 Hedges’s g 表示。（p. 3, Section 2.7）
    • 當可納入研究數 > 5 時，以 random model 計算 summary effect；文中提及 Comprehensive Meta-analysis software，之後又說所有 data 使用 Stata 18.0 結合，兩者的精確分工未完整交代。（p. 4, 6, Sections 2.8）
    • Heterogeneity 使用 Cochran’s Q 與 I²；作者以 25%、50%、75% 對應 small、medium、large heterogeneity。（p. 4, Section 2.8）
    • Publication bias 使用 Rosenthal’s fail-safe N、Egger’s regression test，並呈現 funnel plot。（p. 3, Section 2.5；p. 7–9, Section 3.5 and Figure 3）
    • Subgroup analyses 比較 CRED-nf quality group 與六類 moderator；統計顯著標準為 p < 0.05。（p. 4–6, Section 2.8）

    Detailed Results

    Result Area 1 — Included Evidence and Protocol Diversity

    • Evidence or statistics:
      • 主文報告 25 studies 進入 qualitative synthesis、21 studies 進入 meta-analysis；4 studies 因無法取得足夠結果計算 effect size 而排除 quantitative synthesis。（p. 4–6；Figure 1；Section 3.1）
      • 多數研究為 precision movements，如 archery、shooting、dart throwing、golf putting；另有 dance、dynamic balance、cycling endurance 等。（p. 6, Section 3.2）
      • 常見 EEG targets 為 alpha、SMR、theta、beta；Cz / Pz 與 sensorimotor-region electrodes 經常出現。（p. 6, Section 3.2）
      • NFT dose 由單次短期 intervention 到多次、跨數月 intervention；control conditions 亦高度不一。（p. 5–6, Table 1 and Section 3.2）
    • Interpretation boundary:
      • 這些是 corpus characteristics，不等於各 protocol 的相對效果比較；precision sports 在 corpus 中占多數，因此 pooled result 對 open-skill、快速變動、全身性運動的可轉移性有限。
    • Source locator: p. 5–6, Table 1；Sections 3.1–3.2.

    Result Area 2 — Risk of Bias and CRED-nf Quality

    • Evidence or statistics:
      • 作者稱沒有納入分析的研究在所有 assessed domains 都達到 low risk。（p. 6, Section 3.3）
      • 81% 研究報告 random allocation；只有 1 study 提供足夠 allocation-concealment 資訊；只有 1 study 使用 double-blind design。（p. 6–7；Figure 2）
      • 大多數研究在 baseline comparability、follow-up completeness、intention-to-treat / adherence-related criteria、between-group comparison 與 variability reporting 表現較佳，但 reporting bias 因缺乏 individual-study preregistration 多被判為 unclear。（p. 6–7, Section 3.3；Figure 2）
      • CRED-nf 最不一致的五項為：是否提供 participant strategy（3b）、online data processing / artifact correction（3d）、reinforcement schedule（4b）、regulation success（5a）、regulation-success 與 behavioral-outcome correlation（6b）。（p. 6, Section 3.4；p. 8, Table 2）
    • Interpretation boundary:
      • PEDro 與 CRED-nf 衡量的是不同層次的 trial quality / neurofeedback reporting-design features；CRED-nf 高分不能自動證明 intervention 本身有效，也不能排除 reporting quality 與其他 study characteristics 共變。
    • Source locator: p. 6–8；Figure 2；Table 2；Sections 3.3–3.4.

    Result Area 3 — Overall Meta-analytic Effect

    • Evidence or statistics:
      • Pooled effect：Hedges’s g = 0.78, 95% CI [0.49, 1.07]，Z = 5.31，p 報告為 0.00；異質性 I² = 55.53%，作者稱為 medium-level heterogeneity。（p. 6, Section 3.5；p. 9, Figure 3A）
      • Figure 3A 顯示個別 study effects 方向與大小差異明顯，包含接近零、負向與大幅正向的估計值；因此 pooled positive effect 並不代表所有研究一致受益。（p. 9, Figure 3A）
    • Interpretation boundary:
      • 整體 g = 0.78 支持「在本納入 corpus 中，NFT condition 平均優於 control」的統合結果，但不證明任一特定 EEG band、electrode placement、feedback modality 或 sport task 都有同樣效果；I² 亦顯示研究效果不是單一同質分布。
    • Source locator: p. 6, Section 3.5；p. 9, Figure 3A.

    Result Area 4 — CRED-nf Methodological-Quality Subgroup

    • Evidence or statistics:
      • CRED-nf higher-than-median：g = 1.07, 95% CI [0.65, 1.50], I² = 58.77%。（p. 7；p. 10, Figure 3C）
      • CRED-nf lower-than-median：g = 0.49, 95% CI [0.15, 0.83], I² = 36.11%。（p. 7；p. 10, Figure 3C）
      • Between-group difference：Q(1) = 4.46, p = 0.03。（p. 7；p. 10, Figure 3C）
    • Interpretation boundary:
      • 這是以 study-level checklist score 做 median split 的 subgroup association。它顯示兩群 pooled effects 不同，但不能單憑此分析推論「方法品質提高會因果性地放大 NFT 真實效果」；publication year、task type、control condition、sample、protocol novelty 等仍可能與 quality score 共變。
    • Source locator: p. 7, Section 3.5；p. 9–10, Section 4.1 and Figure 3C.

    Result Area 5 — Expertise and Other Moderators

    • Evidence or statistics:
      • **Expert：**g = 0.60, 95% CI [0.30, 0.90]；**Novice：**g = 1.23, 95% CI [0.65, 1.81]；between-group Q(1) = 3.59, p = 0.06，僅接近顯著。（p. 7；p. 10, Figure 3D）
      • **Integrated vs unintegrated：**g = 0.84 vs 0.73；Q(1) = 0.15, p = 0.70。（p. 10, Figure 3D；p. 11, Section 4.3）
      • **Sessions：**1–3 sessions g = 1.08 [0.58, 1.58]；4–8 sessions g = 0.53 [-0.29, 1.35]；9+ sessions g = 0.61 [0.28, 0.95]；overall subgroup difference Q = 2.60, p = 0.27。（p. 10, Figure 3D；p. 11, Section 4.4）
      • **Performance type：**precision g = 0.80、other g = 0.75；subgroup p = 0.89。（p. 10, Figure 3D）
      • **Training target：**single g = 0.77、multiple g = 0.82；subgroup p = 0.89。（p. 10, Figure 3D）
      • **Personalized/specific instruction：**SI g = 0.87、GI g = 0.72；subgroup p = 0.60。（p. 10, Figure 3D）
    • Interpretation boundary:
      • novice effect 較大只是 near-significant moderator pattern，不能下結論認為 novice 必然比 expert 更適合 NFT。
      • 其餘 p > 0.05 代表本資料沒有足夠證據支持 subgroup difference，不等於證明兩種設計「等效」；各 subgroup 的研究數小、分類粗糙且 protocol heterogeneity 高。
    • Source locator: p. 7, Section 3.5；p. 10–11, Figure 3D and Sections 4.2–4.5.

    Result Area 6 — Publication Bias

    • Evidence or statistics:
      • 作者報告 Rosenthal’s fail-safe N 與 Egger’s test 均未提示 publication bias；funnel plot 亦未見明顯 asymmetry。（p. 7, Section 3.5；p. 9, Figure 3B）
    • Interpretation boundary:
      • 「未檢出」不等於排除 publication bias，尤其 corpus 僅約 21 個 quantitative studies 且存在異質性；本文主文沒有提供足以證明 bias 不存在的額外 sensitivity framework。
    • Source locator: p. 7, Section 3.5；p. 9, Figure 3B.

    Discussion

    Authors’ Discussion

    Conclusions

    • 作者認為 EEG NFT 對 sport performance 有中度正向影響，整體 Hedges’s g = 0.78。（p. 7–9, Section 4；p. 12, Section 5）
    • 作者將較高 CRED-nf score 與較大 pooled effect 視為重要發現，並以此強調未來 neurofeedback 研究需要更嚴謹、標準化的 study design 與 reporting。（p. 9–12, Sections 4.1 and 5）
    • 作者不主張目前資料已確認 integration、session number、performance type、training-target number 或 personalized feedback 是可靠 moderator；expertise 僅呈 near-significant pattern。（p. 7, 10–11）

    Explanations

    • 作者提出，不同研究的方法學嚴謹程度可能是先前 NFT literature 結果不一致的原因之一；higher-CRED studies 較常報告 participant strategies、online data processing / artifact correction、reinforcement schedules、regulation success 與 regulation-behavior correlations。（p. 9–11, Section 4.1）
    • novice 的較大 effect 可能與 learning stage / 可改善空間不同有關，但作者同時指出跨運動 expertise 定義不一致。（p. 11, Section 4.2）
    • integrated NFT 未呈顯著優勢，作者認為可能是不同研究的 training instructions 與 protocols 過度多樣，且直接比較 integrated vs unintegrated 的 evidence 仍有限。（p. 11, Section 4.3）
    • 少於 3 sessions 的 studies 反而呈現較大 pooled effect；作者注意到這些近年研究多採 integrated、single-target、precision-based 設計，因此短期效果可能反映不同 training mechanism，而不是單純「越少 session 越好」。（p. 11, Section 4.4）
    • 作者特別強調 function-directed verbal instruction，認為明確引導 participant 進入與目標 brain function 相關的 mental state，可能降低不必要 cognitive demand 並改善 neurofeedback learning。（p. 11–12, Section 4.5）
    • 作者以 psychomotor efficiency hypothesis 解釋 NFT 後可能出現的較低 conscious control、較高 relaxation 與更自動化的 motor execution，但此機制在本 meta-analysis 中未被直接因果檢驗。（p. 12, Section 4.5）

    Applications

    • NFT protocol 與 target brain region 應有理論與 empirical evidence 支持，並與 sport-specific cognitive / motor demands 對應。（p. 12）
    • 未來 intervention 應納入 sham feedback control、清楚的 step-by-step procedures、依 athlete skill level 與 sport demands 調整訓練。（p. 12）
    • 評估 outcome 時應區分 speed、accuracy、dexterity 等 motor-performance dimensions，以找出哪些表現成分最可能受益。（p. 12）
    • 作者主張應研究適合不同 sport / athlete population 的 training duration 與 frequency，而不是直接將單一 protocol 當作通用處方。（p. 12）

    Limitations

    作者明確提出以下限制：

    • 納入研究在 sample size、participant characteristics、NFT protocols 與 outcome measures 上高度異質，降低 direct comparability 與 generalizability。（p. 12）
    • 許多研究有 inadequate blinding、lack of randomization、small samples、skill-level classification 不一致、control-group strategies 不一致等問題。（p. 12）
    • 多數研究為短期 intervention；作者指出少於 3 sessions 的研究占相當比例，因此 long-term effect 與 sustainability 仍不清楚。（p. 12）
    • 本 meta-analysis 聚焦 motor-performance outcomes，可能忽略 cognitive functions、emotional regulation、physiological responses 等其他 sport-performance dimensions。（p. 12）
    • electrode placement、frequency band 與 feedback modality 不一致，使 protocol-specific conclusion 困難。（p. 12）
    • 以 median split 將 CRED-nf study quality 二分是粗略作法，可能掩蓋連續性的品質差異。（p. 11–12）

    Future Research

    • 以 established theory 與 empirical neural signatures 設計 target brain region / training protocol。（p. 12）
    • 研究 long-term effects 與 retention，確認 performance enhancement 是否持續。（p. 12）
    • 將 motor outcome 分解為 speed、accuracy、dexterity 等可解釋指標。（p. 12）
    • 使用 sham feedback control 以降低 placebo / expectancy explanation。（p. 12）
    • 依 athlete skill level 與 sport-specific demands 設計 NFT，並使用清楚、可重製的 procedure。（p. 12）
    • 釐清不同 sport / athlete populations 的最佳 duration / frequency。（p. 12）
    • 進一步測量 NFT 後 psychological states，以及 regulation success 是否與 behavioral outcome 有可重複的關聯。（p. 8, Table 2；p. 12）

    • 本次提供的 PDF 主文未包含 Appendix S1–S3 / Supporting Information，因此無法核對完整 search strings、全部 CRED-nf coding details 與完整 risk-of-bias supplementary tables；這限制了搜尋與品質評分的完全重製。（p. 3；p. 15）
    • Search-flow 數字在主文與 Figure 1 之間不完全一致：Figure 1 顯示 database records n = 3605、full-text assessed n = 30；Section 3.1 則寫 initially n = 3602，並敘述 title/abstract 後剩餘 27 articles。主文未解釋差異。（p. 4, Figure 1；p. 6, Section 3.1）
    • 作者反覆使用「25 studies included in qualitative synthesis、21 studies in meta-analysis」，但 Table 1 的呈現是 21 列，且部分列將多篇 citation 合併（例如 [4–6]、[7, 17]）。「article」、「study」、「experiment」的 unit-of-analysis 對應未在主文中完全釐清。（p. 5, Table 1；p. 6, Section 3.1）
    • Section 3.5 報告 meta-analysis「total 271 participants」，但 Figure 3A 以 treatment/control arm N 呈現各 effect；主文沒有說明 271 是否為 unique participants、是否排除 crossover 重複計數、或如何與 forest-plot arm counts 對帳。（p. 6；p. 9, Figure 3A）
    • Section 3.5 文字出現「Hedges’s g of 0.78%」，但 abstract、Figure 3A、discussion 與 conclusion 均以 g = 0.78 表示；百分號看來可能是排版或文字錯誤，但本文未說明。（p. 1, 6, 9, 12）
    • Search date 只描述為納入「prior to January 2025」的文章，未在主文提供各 database 的 exact search date。（p. 3, Section 2.2）
    • 本文提及 Comprehensive Meta-analysis software，也在 subgroup-analysis 段落寫「All data were combined using Stata18.0」；兩套 software 的精確分析分工沒有完整交代。（p. 4, 6, Section 2.8）
    • 主文未見 sensitivity analysis（例如只保留 RCT、排除 high-risk studies、依 control type 分層）或 GRADE / certainty-of-evidence assessment；若 supporting files 有提供，本次來源未包含。
    • 作者沒有聯絡原研究作者補取 missing data，因此 4 studies 因資料不足未進入 quantitative synthesis；缺失是否與 effect direction 有關無法從本研究確認。（p. 3–4, Section 2.7；p. 6, Section 3.1）

    Critical Appraisal

    Strengths

    • **範圍比先前 review 更貼近 sport motor performance：**作者刻意排除只測 questionnaire / cognitive test、無 control 等研究，降低「sport performance」與其他 outcome 混用的問題。（p. 2–3, Sections 1 and 2.4）
    • **review-level protocol 與透明度較好：**有 PROSPERO registration、PRISMA framework、multiple reviewers、consensus process 與 reference-list checking。（p. 2–3）
    • **同時使用 generic trial-quality 與 neurofeedback-specific quality lens：**PEDro 可捕捉 randomization / blinding / attrition 等 trial issue，CRED-nf 則進一步檢查 feedback、artifact handling、regulation success 與 behavior linkage，對 NFT literature 特別有資訊價值。（p. 3–4, 6–8）
    • **保留 heterogeneity 與 moderator analysis：**整體 effect 並未被當成完全一致的結果；Figure 3 同時呈現 individual-study effects、CRED subgroup 與多個 moderators。（p. 9–10, Figure 3）
    • **對 null moderator findings 有保留：**作者沒有把 integrated training、session number、performance type、training targets 或 personalized feedback 描述成已被證實的 moderator。（p. 7, 10–11）

    Methodological Concerns

    • **納入 RCT 與 NRS，但未見 design-specific sensitivity analysis：**若 NRS 的 confounding risk 與 RCT 不同，將兩者合併可能影響 pooled estimate；主文沒有呈現只保留 randomized studies 後的 robustness。（p. 3, Sections 2.1 and 2.4）
    • **控制條件高度不一致：**sham、alternate NFT、general training、rest/no intervention 對 expectancy、attention 與 practice effects 的控制程度不同；因此 pooled g 不能被視為對單一 placebo-controlled causal contrast 的估計。（p. 5–6, Table 1 and Section 3.2）
    • **CRED-nf median split 可能混淆 reporting quality 與其他 study characteristics：**higher-CRED studies 可能同時較新、採不同 protocol、不同 task 或不同 participant level。Q(1) = 4.46, p = 0.03 支持 subgroup difference，但不能排除這些共變因子。（p. 7, 9–11）
    • **subgroup power 有限：**多個 moderator 分組的 k 很小，尤其 4–8 sessions 只有 4 studies；因此「沒有顯著 moderator effect」可能是 power 不足，而不是不存在 moderator。（p. 10–11, Figure 3D）
    • **整體異質性仍為中度：**I² = 55.53%，且 tasks、EEG targets、feedback modalities、dose 與 controls 均不同；因此 pooled g 適合描述 field-level average，不足以直接形成可操作的單一 NFT prescription。（p. 6, 9；Table 1；Figure 3A）
    • **少數研究真正具強盲法：**allocation concealment 只清楚出現在 1 study，double-blind 也只有 1 study；performance enhancement 很容易受到 expectancy、coach/researcher interaction 或 practice effects 影響，這削弱對 NFT-specific causal effect 的確定性。（p. 6–7, Figure 2）
    • **English-only 與不聯絡作者取得 missing data：**可能引入 language / availability bias；而被排除的 4 studies 若系統性缺乏 null 或 negative outcomes，publication-bias tests 未必能捕捉這類 selection。（p. 3, Sections 2.2 and 2.7；p. 6）
    • **study-flow reporting 本身有數字不一致：**這不必然改變 meta-analysis 結果，但降低 review process 的可審計性。（p. 4, Figure 1；p. 6, Section 3.1）

    Alternative Interpretations

    • Higher CRED-nf → larger effect 也可能代表較新的研究更常使用 CRED-consistent reporting，同時採用較有效的新 protocol、較聚焦 precision task、較適合 learning 的 novice sample 或更敏感 outcome；因此 quality score 可能是其他設計特徵的 proxy，而非效果更大的原因。
    • Novice > expert 的 pattern 可能來自 ceiling effect、較大的一般 motor-learning space 或對任務本身較不熟悉，而不一定代表 novice 的 neural self-regulation 更容易被 NFT 改變。（p. 7, 11）
    • 1–3 sessions 的較大 effect 可能反映 acute attentional / motivational / expectancy state 或 immediate task practice，而非 durable neuroplastic learning；這與作者同時主張需研究較長 cumulative training / retention 的立場並不矛盾，但目前資料不足以區分兩者。（p. 10–12）
    • 整體正向 performance effect 可能部分來自 non-specific feedback、expectancy、practice 或 researcher interaction，因為多數研究沒有 double-blind 且 control design 不一致。（p. 5–7）
    • 未發現 integrated NFT 優勢 可能不是 integration 無效，而是「integrated」分類過粗，無法區分 feedback timing、task difficulty、instruction content 與 transfer design 的實質差異。（p. 4, 10–11）

    Evidence Needed to Resolve Uncertainty

    • 使用 preregistered、adequately powered、sham-controlled RCT，盡可能納入 assessor blinding / allocation concealment，並依 CRED-nf 完整報告 participant strategy、artifact handling、reinforcement schedule 與 regulation success。
    • 對 regulation success → behavioral change 進行事前規劃的 association / mediation test，而不是只證明 performance improved；並檢查 neural target 是否真的被 participant 有系統地調節。
    • 以 trial-level meta-regression 或 individual-participant-data approach 同時控制 publication year、control type、task type、expertise、sessions、training target 與 CRED score，以分離「方法學品質」與 protocol / sample 特徵的影響。
    • 對 novice 與 expert 使用同一 sport、同一 NFT protocol、同一 control 的直接 factorial comparison，並採量化 skill metric，而不是跨不同 sport 做粗略 expert/novice 分組。
    • 在 single-session 與 multi-session intervention 中加入 delayed retention test，區分 acute state effect、practice effect 與可維持的 learning / performance enhancement。
    • 做 sensitivity analyses：只納入 randomized trials、只納入 sham-controlled trials、排除 high-risk studies、依 precision vs dynamic/open-skill tasks 分層，檢查 pooled g 是否穩定。

    Relevance to My Research

    Claims Supported

    • 「EEG NFT 對 sport motor performance 可能具有整體正向效果」：本 paper 提供 meta-analytic controlled-study evidence，pooled g = 0.78；支持強度為中度，但受 heterogeneity 與 study quality 限制。（p. 6, 9）
    • 「評估 NFT 不應只看 behavioral improvement，還要確認 neural regulation 是否成功」：CRED-nf appraisal 顯示 regulation success 與 regulation-behavior linkage 是既有研究常見缺口，這對設計 manipulation check 有直接方法學價值。（p. 6, 8）
    • 「sport-NFT 的 evidence 目前高度 protocol-dependent」：tasks、frequency bands、electrode sites、sessions 與 controls 高度多樣，支持在新 sport context 中重新驗證，而不是直接搬用 pooled average。（p. 5–6）

    Claims Challenged

    • 「把 NFT 整合進 sport task 一定比 separate NFT 更有效」：本研究的 subgroup difference 不顯著（p = 0.70），因此目前 meta-analytic evidence 不支持必然優勢。（p. 10–11）
    • 「session 越多效果一定越強」：session-number subgroup difference 不顯著，且 1–3 sessions 的 pooled effect 反而較大；不能由現有資料建立單調 dose-response 關係。（p. 10–11）
    • 「personalized feedback、single target 或 precision task 已被證實是效果 moderator」：本研究均未發現顯著 subgroup difference，因此這些主張仍屬待驗證設計假設。（p. 10）

    Design Implications

    • 筆記者推論：若未來設計 sport-NFT 研究，應把 neural regulation success、behavioral performance、兩者關聯 分成三個 evidence layers，而不是只報 performance pre/post；這個轉移需在新 task / population 中重新驗證。（p. 6, 8）
    • 筆記者推論：應優先使用可控制 expectancy 的 sham condition、預先定義 artifact correction / reinforcement schedule，並保留 delayed retention，以區分 acute feedback effect 與 durable learning。（p. 6–8, 12）
    • 筆記者推論：對 dynamic / open-skill sports 不應直接採用 precision-sport pooled effect 作為預期 effect size；本 review corpus 多數來自 putting / shooting / archery 等 precision tasks，需要 task-specific pilot data。（p. 5–6）
    • 筆記者推論：expertise 應用連續或 sport-specific skill metric 描述，而非只用 novice/expert 二分；本文的 near-significant moderator pattern 可作為 preregistered hypothesis，而非既定事實。（p. 7, 11）

    Open Questions

    • higher-CRED studies 的較大 pooled effect，在控制 publication year、task type、control condition、sample size 與 protocol family 後是否仍存在？
    • novice effect 大於 expert 的 near-significant pattern，若在同一 sport、同一 protocol 與量化 skill metric 下直接比較，是否可重現？
    • single-session NFT 的 immediate performance gain 是否能在數天、數週或數月後的 retention test 保留？
    • regulation success 是否真正預測或中介 motor-performance improvement，還是兩者可彼此獨立發生？
    • sham-controlled、double-blind 或至少 assessor-blinded studies 的 pooled effect 是否仍接近 g = 0.78？
    • precision-sport evidence 能否轉移到高動態、open-skill、全身性 motor tasks？目前 corpus 不足以回答。
