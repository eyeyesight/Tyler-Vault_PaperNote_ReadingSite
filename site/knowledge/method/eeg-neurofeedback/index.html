    EEG Neurofeedback

    EEG neurofeedback 把可即時估計的腦電 feature 轉成閉迴路回饋，讓參與者練習 neural self-regulation；方法是否成立，必須同時證明 target 被學會調節、效果具有足夠特異性，且能轉移到沒有回饋的目標行為。

    The Problem

    單純觀察 EEG–performance 關聯，只能指出候選 marker，不能回答人是否能主動改變該訊號，也不能證明改變訊號會改善表現。EEG neurofeedback 將觀察問題改寫為學習問題：參與者能否在回饋協助下，逐步形成對特定 EEG feature 的調節能力？

    這使 neurofeedback 不只是「看見腦波」，而是一個由 measurement、feedback、learning 與 transfer 組成的 closed loop。

    The Logic

    每個 trial 或短時間窗中，系統從 EEG 擷取 target feature，與個人 baseline 或 threshold 比較，再以視覺、聽覺或其他訊號回饋。參與者嘗試策略，系統回報結果，成功狀態受到 reinforcement；重複後才可能形成不依賴即時回饋的 self-regulation。

    核心證據鏈是：

    target rationale → online signal validity → regulation learning → retention → behavioral transfer

    任何一段缺失，都會讓「neurofeedback 有效」產生多種競爭解釋。

    How It Works

    1. Define the target. 根據任務、神經生理假設與個人 baseline 指定 band、site、connectivity 或 multivariate feature，以及增強／抑制方向。
    2. Build the loop. 控制 artifact 與延遲，把即時 feature 映射成可理解且不額外干擾任務的 feedback。
    3. Train over time. 設計 session dose、trial structure、instruction、rest 與 task integration；threshold 應能反映學習，而非只追逐短暫波動。
    4. Test acquisition and transfer. 分別檢查 within-session modulation、across-session learning、移除 feedback 後的 retention，以及 motor／sport outcome。

    Protocol 不是頻帶名稱的同義詞。相同的 SMR 或 alpha 標籤，只要 electrode、方向、任務、feedback、dose 或 baseline 不同，就可能代表不同介入。

    In Practice

    Neurofeedback 評估應同時保留三條結果：neural acquisition、behavioral outcome 與兩者關係。只呈現行為進步，無法判斷參與者是否學會 target；只呈現 EEG 改變，也無法證明技能 transfer。較強設計會使用 sham、active control 或 alternate-feedback 條件，並盡可能匹配 expectancy、接觸時間、練習量與 blinding。

    個體差異不是訓練後才處理的雜訊。Expertise、baseline EEG、可調節性、策略、疲勞與 task fit 都可能影響 responder pattern；但 personalization 應以預先定義 moderator、重複學習曲線或 adaptive rule 檢驗，不能事後把正向個案解釋成精準化成功。

    在 sport 與 motor training 中，task-integrated feedback 可能縮短 lab-to-field 距離，也可能因 dual-task load 干擾動作。是否值得整合，應由目標技能、回饋延遲與移除回饋後的表現決定，而不是假設越接近實際場景越有效。

    What It Produces

    完整的 method output 不是單一 score，而是一組可分離的證據：target feature 是否可可靠估計、參與者是否學會調節、學習是否保留、是否改善 Sport Motor Performance，以及效果是否超過 nonspecific influences。

    這些輸出可用來修正 target selection、dose、control 與個人化假設。它們共同構成方法診斷，而非只為介入貼上 success／failure 標籤。

    The Limit

    Neurofeedback 的即時性不等於 causal specificity。Practice、expectancy、motivation、researcher contact、generic feedback、呼吸或肌肉 artifact 都可能同時改變 EEG 與表現。現有 corpus 的 protocol、control 與 reporting 異質性很高，部分研究未完整報告 regulation success；因此目前只能支持「有潛力且值得以分階段證據鏈檢驗」，不能支持一套通用 frequency protocol，也不能把平均行為改善歸因於特定神經機制。
