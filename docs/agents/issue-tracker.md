# Issue Tracker

This repository uses local Markdown tickets until Tyler explicitly approves a remote repository and tracker.

- One ticket per file: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Number tickets in dependency order.
- Each ticket declares `Blocked by`, `Status`, and behavior-level acceptance criteria.
- `ready-for-agent` means the spec contradiction review is complete and all blockers are resolved.
- Do not create GitHub issues, remotes, or pull requests without explicit approval.
